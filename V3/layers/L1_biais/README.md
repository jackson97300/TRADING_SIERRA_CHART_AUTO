# L1_biais

**le biais 1 h / 4 h — B1, B4, B5, B5b**

Etat : **cadree** — le brief est ecrit, le code ne l'est pas encore.
Cf `../../STATUS.md`.

**Un biais ne rejette pas, il oriente.** Le critere de L0 ne s'y transpose
donc pas : ce qui se mesure n'est pas un taux de rejet mais la **couverture**
(quelle part des barres a un avis), la **separation** (devenir dans le sens du
biais moins devenir contre, avec son intervalle et le controle negatif), et le
**cout de l'obeissance** (les signaux contre le biais, simules en fantomes).

**B1 seul d'abord.** Un biais mesure vaut mieux que quatre ecrits.

Tout est dans [BRIEF.md](BRIEF.md).
